# Portafolio · Sergio Gabriel Cardozo

Sitio estático (HTML, CSS y JavaScript, sin dependencias ni build).

- `index.html`: la página completa.
- `media/`: videos de los proyectos (MP4) y sus imágenes de portada, más la foto de perfil.

## Publicar en Vercel
1. Subí esta carpeta a un repositorio de GitHub.
2. En vercel.com → Add New → Project → importá el repositorio.
3. Framework Preset: **Other**. No hace falta comando de build ni carpeta de salida.
4. Deploy.

Para ver el sitio en tu compu, abrí `index.html` con el navegador.
